## 1. Event bus

- **Ordering:** Per-sender sequence numbers; global ordering by (timestamp, seq) with tie-break.
- **Back-pressure:** Bounded queues; drop lowest-priority with loss accounting.
- **Loss accounting:** LossReport events emitted; no silent loss.
- **Replay:** Replay from local store for recovery and analysis.
- **Memory-safe:** Implemented in memory-safe language.

---

## 2. Case graph

- **Entities:** Process tree (parent/child), persistence mechanisms, touched files, network links, identity context.
- **Incident grouping:** Events correlated by process tree, time window, and detection hits into Cases.
- **Aging:** Cases expire/age out per retention; closed cases archived.
- **Query:** `case_graph.incident(case_id) -> {root_process, descendants[], persistence[], files_touched[], conns[], first_seen, last_seen, tier1_hits[], tier2_score}`.

---

## 3. Encrypted local store

- **Encryption:** At rest using proven crypto (ADR-005).
- **Crash-safe writes:** Write-ahead log / atomic commits; fsync on critical writes.
- **Retention limits:** Per field classification (P0.5): operational 90 d, sensitive 30 d, personal 7 d.
- **Minimisation:** Command lines hashed by default.

---

## 4. Resource governor and watchdog

- **Governor:** Enforces CPU, memory, I/O budgets (P0.2 PB-01..PB-03); load shedding accounted.
- **Self-health:** Heartbeats, memory/CPU sampling, error rates.
- **Watchdog:** Restarts failed components safely; quarantines compromised components; reports to control plane when online. T0 evidence collection continues during restarts.

---

## 5. Modes

| Mode | Behaviour |
|---|---|
| Online | Full operation (observe + detect; actions only after P2) |
| Partitioned | Local detection; no peer-dependent actions |
| Offline | Local detection; no network actions |
| Observe-only (default) | Detection and evidence only; no actions ever (enforced in code) |

Observe-only is the default for new installs and is enforced in code, not configuration alone (RT-008).

---

## 6. Telemetry minimisation

- Field classification from P0.5 applied; no field without classification.
- Free-text instruction-carrying fields marked untrusted (CMP-008).
- Command lines hashed by default.
