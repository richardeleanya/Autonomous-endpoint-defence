## 1. Prediction tasks

| Task | Input | Output | What the model may NEVER decide |
|---|---|---|---|
| Process-behaviour sequence scoring | Sequence of process/file/network events | Score 0..1 + top-5 contributing events | Never authorises containment or any T2+ action |
| Mass-encryption-like I/O pattern scoring | File I/O event window | Score 0..1 + contributing I/O features | Never overrides Tier-1 allowlist or policy engine |
| Suspicious process-tree scoring | Process tree + ancestry | Score 0..1 + top features | Never changes tier assignment |

The model proposes observations only; policy engine decides (MR2).

---

## 2. Datasets

- **Source:** Lab-generated synthetic attack data (safe emulation) + benign corpus from internal lab fleets. No customer data.
- **Licence:** Internal; third-party datasets require licence review (MR18).
- **Labelling:** Weak supervision + manual review by named analysts; labels versioned.
- **Provenance:** Dataset manifest with hash, source, labelling method, date.
- **Privacy:** No personal data; command lines hashed; PII minimised (P0.5 classification).
- **Splits:** Time-based train/test (no random split across time); holdout period reserved for final evaluation.

## 4. Evaluation (TARGETs until measured)

- Precision and recall at operating points (e.g., score >= 0.85).
- False positives on benign corpus per 10,000 endpoint-days.
- Per-OS (Windows/Linux) and per-workload (office, dev, build, DB).
- Calibration error (ECE) reported.
- All results require raw data, method, hardware, workload (MR17).

---

## 5. Robustness

- **Evasion:** Adversarial perturbation tests (synthetic) against feature pipeline.
- **Data poisoning:** Inject poisoned samples in training; measure degradation; retrain with validation.
- **Concept drift:** Monitor score distributions over time; alert on drift beyond threshold (TARGET).

---

## 6. Calibration and explanations

- Scores calibrated via Platt scaling / isotonic regression on holdout set.
- Calibration curve published in model card.
- Explanations: top-5 contributing events/features emitted into the evidence bundle (Observation.evidence_refs).
- Confidence maps to policy thresholds (P0.4): low confidence -> downgraded by R4.

---

## 7. Model lifecycle

- **Signing:** Model artefact signed by release-signing key (P0.3).
- **Staged rings:** Canary (TARGET 1%) -> ring 1 (TARGET 10%) -> full fleet; halt on regression.
- **Drift monitoring:** Score distribution, FP rate, latency monitored; alert on threshold breach.
- **Rollback:** Revert to previous signed model version.
- **Model card:** Published with task, eval, operating point, results, limits, known weaknesses.
