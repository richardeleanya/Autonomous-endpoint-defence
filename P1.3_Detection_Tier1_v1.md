## 1. Rule format and engine semantics

- **Format:** Declarative rules with `when` conditions over canonical events; outputs an Observation with confidence, evidence references, matched rule ID.
- **Engine:** Pure function `detect(event_window, rules, context) -> observations`. Deterministic, bounded evaluation cost (max rules, max window size, timeout). Explainable: each observation cites rule ID and matched evidence event IDs.
- **No side effects; no network; no clock reads except supplied trusted time.**
- **Evaluation order:** Rules evaluated in priority order; all applicable rules fire (multi-match allowed); deduplication by case graph later.

## 4. Confidence calibration

- Confidence values trace to policy thresholds (P0.4): rules with confidence < threshold are downgraded by R4.
- Calibration method: benign corpus replay + synthetic emulation; adjust thresholds to meet FP target (TARGET: <=1 false block per 10,000 endpoint-days).

---

## 5. Content pipeline

1. **Lint:** Schema validation, MITRE mapping, confidence range, required fields.
2. **Replay:** Run rules against benign corpus; measure FP rate.
3. **Staged release:** Canary (TARGET 1%) -> ring 1 (TARGET 10%) -> full fleet; halt on FP spike.
4. **Deprecation:** Versioned rules; deprecated rules retained for audit; removal after 2 releases.
